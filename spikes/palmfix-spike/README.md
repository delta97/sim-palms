# palmfix-spike (SPIKE-001 / SPIKE-002 test project, source files only)

- **Sim:** MSFS 2024 1.9.24.0 (Steam). **SDK:** 1.8.2 (Core). Captured 2026-11-22.
- **Contains:** project `palmfix-spike`, package `cole-palmfix` (SCENERY, asset groups ContentInfo + BGL `Scene`), and a scene
  with two 12-sided exclusion polygons (radius 6 m) at the ADR-0005 Pacific Beach block:
  A = `ExcludeTIN` only around palm `sdpb-8a03f7f6752f55c8` (32.794425, -117.251520);
  B = `ExcludeTIN` + `VegetationDensity 0` around palm `sdpb-e6ea40b0410d50ac` (32.794239, -117.252341).
- **Scene source** is generated by `make_scene.py` from the documented polygon attributes (SDK docs, Scenery XML Properties) and
  validates against `C:\MSFS 2024 SDK\Tools\bin\bglcomp.xsd`. The Scenery Editor was not used (Dev Mode is unstable on this PC).
- **The live project** is in `C:\Users\colep\OneDrive\Documents\MyFSProjects\palmfix-spike\`; the original empty scene is saved
  there as `Scene.xml.empty-backup`. Not in the repo: the SDK default thumbnail and all build output.

Regenerate the scene:

```bash
python spikes/palmfix-spike/make_scene.py spikes/palmfix-spike/PackageSources/Scenery/palmfix/Scene/Scene.xml --xsd "C:/MSFS 2024 SDK/Tools/bin/bglcomp.xsd"
```
