# Findings

Facts confirmed by running things: Phase 0 spike results, in-sim observations, measured build times,
data-source field checks. One file per task: `docs/findings/<TASK-ID>.md`.

Each findings note records: date, sim version, SDK version (where relevant), what was tried, what happened,
screenshots or measurements (paths), and a direct answer to every question the task asked.

Findings outrank plan text. When a finding contradicts a plan, update the detailed plan and link the finding.
