## Goal

A `palmfx.offline` Python package with the session directory layout, mask read/write, and a `palmfx` CLI that discovers subcommands from `palmfx/offline/commands/`. Every later FX task adds files without editing shared ones.

## Context

- Repo root plays `palmfix/` in plan 01. Do not create a nested `palmfix/`.
- `pyproject.toml` is created by ARCH-001, extended by ARCH-009 (`palmfix` script) and possibly topped up by SCAN-001; this task runs after both, so no two unordered tasks edit it. Only add what is listed in Steps; don't restructure it.
- Formats are defined in the plan_ref sections "Session data formats" and "Mask formats". Implement exactly those.
- `data/` should already be gitignored by ARCH-001. Do not edit `.gitignore` here; if `data/fx/` is not ignored, log it on this task and tell the ARCH owner.

## Steps

1. Create `palmfx/__init__.py` (empty), `palmfx/offline/__init__.py` (version string), `palmfx/offline/__main__.py` (calls `cli.main()`).
2. `palmfx/offline/cli.py`: `main(argv=None) -> int`. Builds an `argparse` parser with subparsers; imports every module in `palmfx.offline.commands` via `pkgutil.iter_modules` and calls its `register(subparsers)`. Each command sets `func`; `main` calls it and returns its exit code. A module with no `register` is skipped with a warning.
3. `palmfx/offline/commands/__init__.py`: empty, plus a docstring describing the `register(subparsers)` contract and that every command takes `--session`.
4. `palmfx/offline/session.py`: `FrameRecord`, `MaskSet`, `Session`, `open_session`, `new_session`, `read_mask`, `write_mask` with the signatures in "Python interfaces". `Session.frames()` reads `frames.jsonl`. `write_mask` writes `NNNNNN.png` (0/255 uint8), `NNNNNN.inst.png` (uint16) and `NNNNNN.json`. `read_mask` derives instances from 8-connected components when `.inst.png` is missing. Image I/O through OpenCV (`cv2.imread(..., cv2.IMREAD_UNCHANGED)`), RGB order in memory.
5. In `pyproject.toml`: add `[project.optional-dependencies]` groups `fx = ["numpy", "scipy", "opencv-python-headless", "scikit-image", "pyproj", "pyyaml", "matplotlib"]` and `fx-lama = ["torch"]`; add `[project.scripts] palmfx = "palmfx.offline.cli:main"`; add `"palmfx"` to `[tool.hatch.build.targets.wheel] packages` (ARCH-001 lists `palmcore`, `palmscan`, `palmgen` explicitly).
6. `palmfx/README.md`: 15-line overview: what Stage A is, where data lives (`data/fx/`), `pip install -e .[fx]`, `palmfx --help`, link to the plan_ref.
7. Tests: `tests/unit/palmfx/test_session.py` (new_session/open_session round trip, frames.jsonl parsing, write/read mask round trip incl. 16-bit labels, instance derivation without `.inst.png`); `tests/unit/palmfx/test_cli.py` (a dummy command module registered via monkeypatched discovery runs and returns 0; `palmfx --help` exits 0).
