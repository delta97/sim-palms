## Goal

Blob masks detected from the image alone (raw depth + colour), with no palm database and no calibration. This is the fallback if projection doesn't line up, and the comparison point for it.

## Context

- Algorithm and starting thresholds are in the plan_ref (A8). Thresholds are for 1440 p; scale pixel sizes by `H/1440`.
- Works on `frames/NNNNNN.depthraw.npy` only; gradients of `ln d` are scale-free. If `session.json` says depth is not reversed, negate `L`.
- Thresholds are starting values. Tuning on real data happens in FX-019 and must be recorded there, not hard-coded here.

## Steps

1. `palmfx/offline/config/heuristic.yaml`: every threshold from the plan_ref A8 (protrusion 0.10, opening width 61, HSV ranges, edge 0.08, close 5, min height 24, aspect 1.2, fill 0.4, edge support 0.3, dilate 3, reference height 1440).
2. `palmfx/offline/mask_heuristic.py`: `HeuristicParams.from_yaml(path)`; `heuristic_masks(color_rgb, depth_raw, params, reversed=True, occluder=None) -> MaskSet`. Steps 1-7 of the plan_ref, using `scipy.ndimage.grey_opening`, `cv2.cvtColor(..., cv2.COLOR_RGB2HSV)`, `cv2.Sobel`, `cv2.morphologyEx`, `cv2.connectedComponentsWithStats`. Store per-component diagnostics (height, aspect, fill, edge support, reason rejected) in `params["debug"]` when `debug=True`.
3. `palmfx/offline/commands/mask_heuristic.py`: `palmfx mask-heuristic --session DIR [--config YAML] [--debug]`; with `--debug` also writes `masks/heuristic/debug/NNNNNN.png` (candidates in yellow, kept in green, rejected in red).
4. `tests/unit/palmfx/test_mask_heuristic.py` on the synthetic scene: IoU vs GT ≥ 0.7; the grey building (wrong colour, wide) is rejected; a green but flat lawn patch with no protrusion is rejected; thresholds scale with image height (render at 2× size and get the same instance count).

## Acceptance criteria

- [x] All thresholds come from the YAML file; none are hard-coded in the function body.
- [x] Synthetic tests pass.
- [x] Debug overlay explains every rejection.
