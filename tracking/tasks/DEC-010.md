## Goal

If DEC-001 chose to publish, the user decides per data source what derived data ships (compiled region packages, `palms.geojson`, neither), recorded in ADR-0011. Dropped if DEC-001 chose personal.

## Context

- Region packages contain palm coordinates, sizes and cut polygons derived from inventories, LiDAR, OSM and footprints. `palms.geojson` contains the same data in raw form plus `source_ids`.
- Procedure: `plans/detailed/07-risks-and-open-questions.md#how-every-decision-task-runs`.
- Evidence: `docs/licenses/data-sources.md` (re-checked by DEC-001), ADR-0002, ADR-0010 (footprint source), ADR-0012 (regions).
- Options: (1) compiled packages only; (2) packages plus `palms.geojson`; (3) tools only, users build regions themselves; (4) per-source mix: packages for regions whose sources have clear terms, tools only elsewhere.
- Default if unclear: option 4.
- This task records the user's choice. It does not decide legal questions; it lists them and the user's stated position on each.

## Steps

1. For each region in ADR-0012, list its sources and each source's terms status from the license doc.
2. For each option, write what a user would download and which sources' data it contains.
3. Ask the user to choose per region, and to state their position on each open question from the license doc.
4. Write `tracking/decisions/ADR-0011-data-redistribution.md`, then set Status `accepted` with the per-region choice table.
5. Consequences: rules for package contents (for example "no `palms.geojson` in packages", "strip `source_ids`"), input for RISK-009 (which credits are needed), release-notes text. Note any GEN change needed (for example a packaging flag) as a task for the GEN owner.
6. Add a one-line `Decided (ADR-0011): ...` note to the Phase 6 section of `plans/detailed/05-phases.md` (if missing, note in the ADR).
7. Run `python3 scripts/tasks.py validate`.

## Acceptance criteria

- [ ] ADR-0011 has a per-region table: region | sources | what ships.
- [ ] The user's position on each open license question is recorded (or "unanswered", in which case that source ships tools only).
- [ ] Status `accepted` (or `proposed` with default applied provisionally).
- [ ] `plans/detailed/05-phases.md` carries the decision note.
