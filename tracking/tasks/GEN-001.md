## Goal

`palmgen` exists as an importable package with its full CLI (every subcommand and flag from the plan), exit-code exceptions, shared dataclasses and default-path rules. Later GEN tasks fill in functions without editing `cli.py`.

## Context

- Spec: plan sections [palmgen CLI](../../plans/detailed/04-fs2024-integration.md#palmgen-cli), [palmgen Python API](../../plans/detailed/04-fs2024-integration.md#palmgen-python-api) (model.py part) and [GEN skeleton and CLI](../../plans/detailed/04-fs2024-integration.md#gen-skeleton-and-cli).
- ARCH-001 provides the repo scaffold, `pyproject.toml`, lint and pytest setup. Do not edit `pyproject.toml`; if it lacks the `palmgen = "palmgen.cli:main"` console script, note it in the Log for the ARCH owner. `python -m palmgen` must work regardless.
- GATE-P0 must be passed (Exclude TIN works on the current sim) before generator work starts.

## Steps

1. `palmgen/__init__.py`: `__version__ = "0.1.0"`.
2. `palmgen/errors.py`: `PalmgenError(Exception)` with class attribute `exit_code`; subclasses `InputError` (2), `GenerationError` (3), `CompileError` (4), `OutputCheckError` (5), `SimRunningError` (6), `ToolUnavailableError` (7).
3. `palmgen/model.py`: dataclasses `Palm`, `Cluster`, `ExclusionPolygon`, `Placement`, `TileContent`, `BuildWarning`, `GenerateResult`, `CompileResult`, `Check` exactly as in the plan (frozen except `GenerateResult`).
4. `palmgen/paths.py`: `default_config(region)`, `default_palms(region)`, `default_buildings(region)`, `default_airports(region)`, `default_manifest()`, `project_dir(out, region)`, `package_name(region)` returning `Path`/`str` per the plan defaults (`regions/NAME.yaml`, `data/NAME/palms.geojson`, `data/NAME/buildings.geojson`, `data/NAME/masks/airports.geojson`, `assets/manifest.json`, `<out>/palmfix-NAME`, `palmfix-NAME`). Paths are relative to the current working directory.
5. `palmgen/cli.py`: argparse with subcommands `build`, `index`, `masks airports` and every flag listed in the plan, with the listed defaults and `choices`. `main(argv=None) -> int`. Dispatch lazily (import inside the handler) to `palmgen.pipeline.run_build(opts)`, `palmgen.spatial_index.run_index(opts)`, `palmgen.masks.run_fetch_airports(opts)`. Catch `PalmgenError` → print `error: <message>` to stderr, return `exit_code`; `ImportError`/`NotImplementedError` from a missing stage → message `"<stage> is not implemented yet"`, return 1. Region name must match `^[a-z0-9]+(-[a-z0-9]+)*$` else exit 2.
6. `palmgen/__main__.py`: `raise SystemExit(main())`.
7. Tests: `--help` for each subcommand exits 0; bad `--placement` value exits 2; bad region name exits 2; a stubbed stage returns 1 with the message; `paths` defaults.

## Acceptance criteria

- [ ] `python -m palmgen build --help`, `index --help`, `masks airports --help` list every flag in the plan.
- [ ] Exit codes map exactly as in the plan table.
- [ ] `cli.py` imports no heavy modules (shapely, lxml) at import time.
- [ ] Unit tests pass and lint is clean.
