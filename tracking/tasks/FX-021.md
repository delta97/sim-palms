## Goal

STAGE B, coarse. Only after FX-100 = GO; on NO-GO this task is dropped. A minimal C++ ReShade add-on that loads in MSFS 2024, gets the colour and depth resources each frame, copies a tile around a screen rectangle into a staging texture, and draws a debug overlay. Re-break this task into smaller ones when it becomes workable.

## Context

- Shape and blockers in the plan_ref. FX-001's `palmfx/docs/depth-access.md` has the depth settings that worked.
- Use the ReShade add-on API (`reshade.hpp`, docs at https://crosire.github.io/reshade-docs/). Do not assume event names or behaviour from memory; read the headers of the ReShade version in use and cite it.
- VERIFY: whether the standard ReShade build loads third-party add-ons in MSFS 2024 or the "full add-on support" build is needed, and what that means for online use (see FX-001 findings).

## Steps

1. Re-read FX-100's Stage B implications and the plan's blockers list; split this task into 2-4 smaller tasks if it won't fit in 6 h, and log that.
2. CMake project in `palmfx/addon/` building a `.addon64` against the ReShade headers of the version in `depth-access.md`.
3. Register for the events needed to get the back buffer and the depth resource each frame (find them in the API docs; record names and why).
4. Copy one fixed tile (e.g. 256×256 at screen centre) of colour and depth to a staging texture; show it in the ReShade overlay as a debug window.
5. Record in `palmfx/addon/README.md`: build steps, ReShade version, which build type was needed, observed per-frame cost of the copy (rough, via the overlay or PresentMon).

## Acceptance criteria

- [ ] Add-on builds and loads in MSFS 2024 with photogrammetry on.
- [ ] Debug overlay shows the live colour and depth tile.
- [ ] README records build, ReShade version and build type.

## Verification

Manual, Windows: build with `cmake -S palmfx/addon -B build/palmfx-addon && cmake --build build/palmfx-addon --config Release`, copy the `.addon64` next to the ReShade DLL, start MSFS 2024, open the ReShade overlay, see the add-on listed and the debug tile updating while flying.
