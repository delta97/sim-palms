## Goal

`palmgen/masks.py` drops palms inside `mask_out` areas and airport masks, clips exclusion polygons out of airport areas, and can fetch aerodrome polygons from Overpass into `data/<region>/masks/airports.geojson` (`palmgen masks airports`).

## Context

- Spec: plan section [GEN masks](../../plans/detailed/04-fs2024-integration.md#gen-masks) and the `mask_out`/`masks.airports` keys in [Region config keys palmgen reads](../../plans/detailed/04-fs2024-integration.md#region-config-keys-palmgen-reads).
- Unit tests never hit the network: inject the HTTP function. The real fetch is run during region setup (REGION tasks), with `network`.
- OSM data is ODbL: keep an `attribution` member in the written file.

## Steps

1. `Mask` dataclass; `load_masks(cfg, airports_path, region_yaml_dir, projection)`: inline geometries and `path` entries (relative to the YAML dir); airport file when enabled, buffered in metres; missing airport file → `InputError` with hint.
2. `apply_point_masks(palms, masks)` → `(kept, {mask_name: [palm_ids]})`; a palm in two masks is counted under the first by config order.
3. `clip_polygons_by_masks(polys_local, masks_local, kinds={"airport"})` → clipped polygons plus `{mask_name: n_clipped}`; parts below `min_part_area_m2` dropped.
4. `overpass_to_geojson(resp)`; `fetch_airports(bbox, out_path, endpoint, http_post=None)` (default uses `urllib.request`, 90 s timeout, generic User-Agent `palmgen`); `run_fetch_airports(opts)` for the CLI.
5. Fixtures: `masks_small.geojson` (one mod polygon file referenced by `path`), `overpass_airports.json` (1 closed way + 1 multipolygon relation, hand-written), `airports_small.geojson` (expected conversion, also used by GEN-012 as the fixture region's airport file).
6. Tests: point masking counts; airport clip removes overlap; missing-file error; Overpass conversion equals `airports_small.geojson`; `fetch_airports` with a fake `http_post` writes the file and returns the feature count.

## Acceptance criteria

- [ ] Masked palms are reported per mask name.
- [ ] Airport masks clip polygons; mod masks don't.
- [ ] `palmgen masks airports` works with an injected fake HTTP in tests; no network in unit tests.
