## Goal

From a few manually clicked correspondences, fit the camera's vertical FOV, the trigger-to-frame time offset, a small pose bias and the depth model, then write metric depth for every frame. Projection masks and compositing need all four.

## Context

- Method, unknowns, bounds and targets are in the plan_ref (A6). `clicks.json` format is defined there.
- The clicking itself is done by a human in FX-013. This task writes and tests the tools on synthetic data.
- The click UI needs a display (matplotlib). Keep all fitting code separate from the UI so it is testable headlessly.

## Steps

1. `palmfx/offline/clicks.py`: `run_click_ui(session, frames, palms, out_path)` using matplotlib: show a frame with projected palm bases/tops (current calibration or defaults) labelled by `palm_id`; left click records a point, then a text prompt takes `palm_id` and `base|top` (or `w` for a free world point, prompting lat, lon, h); `u` undoes; `n` next frame; saves `clicks.json` after every click. `load_clicks(path)` and `save_clicks(path, clicks)` helpers.
2. `palmfx/offline/calib.py`: `calibrate(session, clicks, palms) -> CalibResult`:
   - world point for each click (palm base at `ground_elev_m`, top at `ground_elev_m + height_m`, or the free world point);
   - for each offset in −150..+150 ms step 5: re-interpolate poses at `t_trigger + offset` (use `timing.interpolate_poses`), then `scipy.optimize.least_squares` (loss `huber`, `f_scale=3`) over `vfov_deg` (start 60, bounds 20-120), `d_heading/d_pitch/d_bank` (±5°), `d_body_m` (±5 m each); keep the best; refine offset at 1 ms around it;
   - depth model: sample `d` (median 5×5) at each clicked base, pair with fitted `z`, `depth.fit_depth_model`;
   - return `CalibResult` with `rms_px`.
3. `palmfx/offline/commands/calib.py`: `palmfx calib --session DIR --palms GEOJSON` writes `calib/intrinsics.json`, `time_offset.json`, `pose_bias.json`, `depth_model.json`, re-runs ingest with the offset, then writes `frames/NNNNNN.depth.npy` via `to_metric`. Prints RMS and warns if above the plan_ref targets (8 px at 1440 p, scaled; 5 % depth).
4. `palmfx/offline/commands/clicks.py`: `palmfx clicks --session DIR --frames 0,15,30,45,59 --palms GEOJSON`.
5. `tests/unit/palmfx/test_calib.py`: synthetic session with true vfov 55°, offset +40 ms, heading bias 1.0°; synthesise exact clicks (8 per frame, 5 frames) plus 1 px noise; `calibrate` recovers vfov within 0.5°, offset within 5 ms, heading bias within 0.2°, `rms_px` < 2; depth model `a` within 2 %.

## Acceptance criteria

- [ ] Synthetic recovery test passes.
- [ ] `palmfx calib` writes all four calib files and metric depth for every frame.
- [ ] Click UI saves after every click and can resume from an existing `clicks.json`.

## Verification

```bash
pytest tests/unit/palmfx/test_calib.py -q
```

Manual (any desktop with a display): `palmfx clicks --session <synthetic session dir> --frames 0 --palms <synthetic palms>`; click two points, close, check `calib/clicks.json` has two entries.
