## Goal

Hand-painted blob masks for 6 frames, clicked camera correspondences for both sessions, a calibrated session, and a small committed sample fixture. These are the ground truth for C1 and for real-data regression tests.

## Context

- Masks: rules in the plan_ref (A9). Clicks: format and counts in A6. Fixture builder: `palmfx fixture` from FX-008.
- Needs a desktop with a display and an image editor (GIMP or Krita). Runs where `data/fx/` lives (normally the user's PC).
- Use the DEC-004 block's `palms.geojson` from SCAN-100.

## Steps

1. Ingest both sessions: `palmfx ingest --session data/fx/<sid>`.
2. Clicks: `palmfx clicks --session data/fx/<sid> --frames 0,15,30,45,59 --palms <palms.geojson>`; ≥ 8 points per frame, mixing palm bases and tops; add free world points if fewer than 8 palms are visible.
3. Calibrate: `palmfx calib --session data/fx/<sid> --palms <palms.geojson>`. Record RMS and offset in `palmfx/docs/labelling.md`. If RMS is above target, add clicks on 2 more frames and re-run once; record the final values either way.
4. Hand masks: for each session, frames at start, middle and end (3 per session). Paint every visible blob in a separate layer, whole blob including soft edges, no shadow; export 8-bit 0/255 PNG to `data/fx/<sid>/masks/hand/NNNNNN.png`. Note frames, time spent and any unsure blobs in `labelling.md`.
5. Fixture: `palmfx fixture --session data/fx/<low sid> --out tests/fixtures/palmfx/sample-seq --frames <the 3 hand-masked frames plus 2 between> --scale 0.25 --palms <palms.geojson>`. Add `tests/fixtures/palmfx/sample-seq/README.md`: source session, date, sim build, scale, licence note (frames are screenshots of MSFS 2024 for testing only).
6. Write `palmfx/docs/labelling.md`: procedure as done, counts, calibration results, problems.

## Acceptance criteria

- [ ] `masks/hand/` has 3 frames per session; total blob instances ≥ 20.
- [ ] `calib/` complete for both sessions; RMS recorded.
- [ ] `tests/fixtures/palmfx/sample-seq/` committed, < 5 MB, with README.
- [ ] `palmfx/docs/labelling.md` written.
