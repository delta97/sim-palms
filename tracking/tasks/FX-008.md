## Goal

`palmfx ingest` turns a raw capture into `frames/` + `frames.jsonl` with decoded depth and an interpolated pose per frame. `palmfx fixture` makes the small committed sample set.

## Context

- Steps and formats are in the plan_ref (A4) and "Session data formats".
- Time offset between trigger and actual frame is unknown; ingest reads `calib/time_offset.json` if present, else uses 0. FX-009 fits it and re-runs ingest.
- Before/after file pairing depends on ReShade's naming, recorded by FX-001 in `palmfx/docs/depth-access.md`. Make the suffixes configurable (`--before-suffix`, `--after-suffix`) with defaults taken from that doc if it exists when you start; otherwise defaults that match FX-004's fake session.
- Tests use FX-004's `synth_session_dir`. If FX-004 is not merged yet, build a minimal fake session inline in the test with the same format.

## Steps

1. `palmfx/offline/timing.py`: `interpolate_poses(rows, t_ns, max_gap_ms=50)`: positions via `LocalFrame` ENU, linear; attitude via `scipy.spatial.transform.Rotation` / `Slerp` on canonical angles (apply `simvar_conventions` first); returns canonical pose dicts or `None`, plus `pose_gap_ms`.
2. `palmfx/offline/ingest.py`: `ingest(session, max_gap_ms=50, drop=())`:
   - list `raw/reshade/`, pair before/after, sort by name then mtime;
   - check count vs `triggers.csv`; on mismatch raise with the list of indices around gaps unless `drop` lists them;
   - write `frames/NNNNNN.color.png` (copy, RGB) and `NNNNNN.depthraw.npy` (`unpack_log24`);
   - `t_ns = t_trigger + offset`; pose via `interpolate_poses`;
   - write `frames.jsonl`.
3. `palmfx/offline/commands/ingest.py`: `palmfx ingest --session DIR [--max-gap-ms 50] [--drop i,j] [--before-suffix S] [--after-suffix S]`.
4. `palmfx/offline/commands/fixture.py`: `palmfx fixture --session DIR --out tests/fixtures/palmfx/sample-seq --frames 0,10,20,30,40 --scale 0.25 [--palms GEOJSON]`. The fixture is a *raw* session (so tests exercise ingest), renumbered 0..N-1 with the original indices stored as `source_frames` in its `session.json`:
   - `raw/reshade/` pairs: colour downscaled with `cv2.INTER_AREA`; packed depth downscaled by stride sampling (never interpolated, since packed values can't be averaged);
   - `raw/triggers.csv` rows for the chosen frames (renumbered) and the `raw/poses.csv` rows within ±200 ms of them;
   - `session.json` with the new resolution; `calib/intrinsics.json` scaled (`width, height, fx, fy, cx, cy` × scale); other `calib/` files copied; `calib/static_occluder.png` and `masks/hand/` downscaled nearest-neighbour and renumbered;
   - `palms.geojson` clipped to 2 km around the frame poses (if `--palms`).
   Fail if the output is > 5 MB.
5. Tests: `test_timing.py` (interpolation exact on linear motion; slerp across heading 359°→1° wraps correctly; gap > max returns None); `test_ingest.py` (fake session ingests to the right count; poses within 0.01 m / 0.01° of the truth at offset 0; mismatch raises; `--drop` recovers; fixture output < 5 MB, decoded fixture depth values are a subset of the source values, and ingesting the fixture works).

## Acceptance criteria

- [ ] `palmfx ingest` on a fake session reproduces the ground-truth poses.
- [ ] Heading wrap-around handled.
- [ ] Fixture builder never interpolates depth and enforces the 5 MB limit.
