## Steps

1. `python -m palmgen build --region <test> --models placeholder` from a clean `build/` dir. Must exit 0.
2. Screenshot T1 and T3 at street, 150 m and 500 m with no fix (package removed), per TEST-102.
3. Install the compiled package into Community (manual junction: `mklink /J <Community>\palmfix-<test> <compiled dir>`), restart the sim, repeat the screenshots.
4. Count visible blobs before/after at T1 (from screenshots) and compute the removal rate.
5. Fill the TEST-102 checklist; write `tracking/logs/GEN-100.md` with versions, counts, removal rate, checklist results, build time.
