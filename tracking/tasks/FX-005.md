## Goal

A ReShade effect that writes the raw depth buffer into the image as 24-bit log-encoded RGB, and a Python decoder plus depth-model helpers. This gets lossless-enough depth out of the sim through plain PNG screenshots.

## Context

- Encoding "log24" is defined in the plan_ref (A2, "Depth packing"). The Python `pack_log24` must mirror the shader exactly, so tests on the Python side stand in for the shader until FX-007 runs it in the sim.
- Use arithmetic only (`floor`, `fmod`, `exp`, `log`) in the shader; don't rely on integer bit intrinsics.
- Sample the depth buffer through ReShade's standard `ReShade.fxh` access. Whether the raw sample is reversed is set by the user's preprocessor flags (FX-001). The effect packs the raw value `d` as read, before ReShade's linearisation, so decode does not depend on far-plane settings. VERIFY in FX-007 that `ReShade.fxh` exposes a raw (non-linearised) depth sample; if it only exposes linearised depth, pack that instead and record `depth_encoding.source = "linearized"` in `session.json`.
- Depth model `z = a / (d + b)` is fitted later (FX-009); this task provides `fit_depth_model` and `to_metric`.

## Steps

1. `palmfx/offline/capture/PalmFxDepthPack.fx`: one full-screen pass; uniform `DMIN = 1e-7`; `v = d < DMIN ? 0 : round((log(d) - log(DMIN)) / (-log(DMIN)) * 16777215)`; `R = floor(v / 65536)`, `G = floor(fmod(v, 65536) / 256)`, `B = fmod(v, 256)`; output `float4(R, G, B, 255) / 255`. Header comment: what it does, which ReShade version it was written against, and the decode formula.
2. `palmfx/offline/depth.py`: `pack_log24`, `unpack_log24`, `DepthModel`, `fit_depth_model` (least squares on `1/z = (d + b) / a`, i.e. linear in `d`; return `rms_rel`), `to_metric` (NaN where `d == 0`), and `read_depth_png(path) -> np.ndarray`.
3. `tests/unit/palmfx/test_depth.py`: round trip on `d` spanning 1e-7 to 1 (log-spaced) has relative error ≤ 2e-6; `d = 0` and `d < dmin` decode to 0; `fit_depth_model` recovers `a = 0.1, b = 0` from synthetic `d = 0.1 / z` with noise 1e-4 relative; `to_metric` gives NaN for sky.
4. Write a 6-line usage note at the top of `depth.py` docstring: how to install the `.fx` into ReShade's shader folder and enable it alone.

## Acceptance criteria

- [ ] Shader file present, arithmetic-only, decode formula documented in its header.
- [ ] Python round-trip and model-fit tests pass.
- [ ] `pack_log24` and the shader use identical constants and rounding.
