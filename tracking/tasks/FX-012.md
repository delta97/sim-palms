## Goal

A metric module and `palmfx mask-compare` command that score one mask method against another (usually against hand masks). Criterion C1 of the go/no-go is computed with it.

## Context

- Formulas in the plan_ref (A9): pixel IoU per frame, greedy one-to-one instance matching at IoU ≥ 0.3, precision, recall, median matched IoU. Static occluder removed from both masks.
- Frames present in only one method are skipped and counted; hand masks exist for only 6 frames.

## Steps

1. `palmfx/offline/mask_metrics.py`: `iou(a, b)` (empty ∪ empty = 1.0); `instance_ious(pred, ref) -> np.ndarray (P,R)`; `match_instances(pred, ref, iou_thr=0.3) -> MatchResult(tp, fp, fn, pairs, matched_ious)`; `compare_dirs(dir_a, dir_b, occluder=None) -> dict` with per-frame and summary values (`pixel_iou_mean`, `pixel_iou_median`, `precision`, `recall`, `matched_iou_median`, `frames_compared`, `frames_skipped`, `empty_empty_frames`).
2. `palmfx/offline/commands/mask_compare.py`: `palmfx mask-compare --session DIR --a METHOD --b METHOD [--iou-thr 0.3]` writes `metrics/mask-<a>-vs-<b>.json` and prints a 5-line summary.
3. `tests/unit/palmfx/test_mask_metrics.py`: hand-built arrays for IoU (identical = 1, disjoint = 0, half overlap = 1/3); matching is one-to-one (two preds on one ref → 1 TP, 1 FP); threshold respected; occluder pixels ignored; frames missing from one side are skipped and counted.

## Acceptance criteria

- [x] Metric functions match the hand-computed values exactly.
- [x] JSON output has every summary key listed in Step 1.
