## Goal

The user confirms which regions get built in Phase 6, in what order, and whether the Florida species set is in scope, recorded in ADR-0012 at the start of Phase 6.

## Context

- Plans: `plans/05-phases.md` Phase 6 (order: San Diego coastal, LA Westside and beaches, rest of LA basin, other SoCal photogrammetry cities; Florida after a Florida species set exists); `plans/03-palm-assets.md` Florida set; `plans/02-detection-pipeline.md` Florida genera.
- Procedure: `plans/detailed/07-risks-and-open-questions.md#how-every-decision-task-runs`.
- Evidence: GATE-P5 result; actual hours for the test region across Phases 1-5 (task logs, RISK-008 entry); inventory availability per candidate city (RISK-001 sources); photogrammetry coverage per city (user check in sim).
- Options: (1) plan order; (2) user's own order; (3) SoCal only, stop after LA basin; (4) add Florida (needs new species assets and genus list).
- Default if unclear: plan order, Florida deferred.

## Steps

1. List candidate regions with: inventory source available (yes/no, which), photogrammetry coverage (user confirms), estimated hours (5-10 per region per plan; adjust with actuals), known mods or airports to mask (`docs/compat/*`).
2. Ask the user where they fly most and whether Florida interests them.
3. Write `tracking/decisions/ADR-0012-scale-out-regions.md` (Status `proposed`).
4. User decides. Consequences: ordered region list with proposed region file names (`regions/<name>.yaml`); note to the REGION owner to create one task per region; if Florida is in, list needed ASSET (4 species) and SCAN (genus list) work.
5. Add a one-line `Decided (ADR-0012): ...` note to the Phase 6 section of `plans/detailed/05-phases.md` (if missing, note in the ADR).
6. Run `python3 scripts/tasks.py validate`.

## Acceptance criteria

- [ ] ADR-0012 has an ordered region list with file names.
- [ ] Florida is explicitly in or out.
- [ ] Status `accepted` (or `proposed` with default applied provisionally).
- [ ] `plans/detailed/05-phases.md` carries the decision note.
