## Goal

`palmgen/inputs.py` loads and validates `palms.geojson`, building footprints and the region YAML into `Palm` objects, shapely polygons and a frozen `GenConfig`. It also creates the shared `*_small` fixtures that later GEN tests reuse.

## Context

- Spec: plan sections [GEN inputs](../../plans/detailed/04-fs2024-integration.md#gen-inputs) and [Region config keys palmgen reads](../../plans/detailed/04-fs2024-integration.md#region-config-keys-palmgen-reads).
- Use ARCH-002's palms validator and ARCH-003's region loader from `palmcore`; don't reimplement schemas. Keys ARCH hasn't added yet fall back to the defaults in the plan table.
- The data-version key in collection metadata is ARCH-002's; just return the collection-level members as a dict.

## Steps

1. `GenConfig` frozen dataclass with every key from the plan table and its default; `load_gen_config(region_name, config_path)`. Unknown keys under `exclusion` → `logging.warning`. `region` in the YAML must equal `region_name` else `InputError`.
2. `load_palms(path, region)`: validate; map properties to `Palm`; `InputError` on schema failure (first 20 errors), duplicate `palm_id`, or a feature whose `region` differs. Return palms sorted by `palm_id` and the collection-level members (everything except `type` and `features`).
3. `load_buildings(path)`: Polygon and MultiPolygon features → list of Polygons (exploded), `make_valid`, drop empties. Missing file → `InputError` with the hint from the plan.
4. Create fixtures per the plan: `palms_small.geojson` (12 palms across 2 tiles with the listed cases; all must pass the ARCH-002 schema), `buildings_small.geojson` (one building touching a palm's circle, one containing a palm), `region_small.yaml` (region `fixture-small`, bbox covering both tiles, one inline `mask_out` of kind `mod` around one palm, `masks.airports.enabled: true`). Put a comment block at the top of the YAML describing each case.
5. Tests for each error path and for defaults.

## Acceptance criteria

- [ ] Fixtures validate against the ARCH-002 schema and the ARCH-003 loader.
- [ ] Every `InputError` path has a test.
- [ ] `GenConfig` defaults equal the plan table.
