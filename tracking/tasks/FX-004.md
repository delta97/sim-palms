## Goal

A tiny analytic ray caster that produces frames with exact ground truth (colour, depth, masks, clean plate, pose, palms). All other offline FX tasks test against it, so they don't need real sim captures.

## Context

- Spec in the plan_ref (A15). Uses `camera.py` from FX-003 for poses and projection.
- Keep it small and fast: 320×180, 8-frame sequences, under 2 s per test module.
- `tests/conftest.py` belongs to TEST. Put fixtures only in `tests/unit/palmfx/conftest.py`.
- Raw depth uses reversed-Z `d = 0.1 / z` (a synthetic choice, not a claim about the sim).

## Steps

1. `palmfx/offline/synth.py`:
   - `SynthScene(palms_enu, box_size=(4, 4, 12), building=((x0, y0), (x1, y1), height), seed)`.
   - `render(scene, pose, K) -> SynthFrame` with fields `color` (uint8 RGB), `depth_raw` (float32, 0 for sky), `depth_m` (NaN for sky), `gt: MaskSet` (instances carry `palm_id`), `clean` (same frame rendered without blobs).
   - Ray casting: per-pixel rays from `camera.backproject`; intersect ground plane `u = 0` and axis-aligned boxes (slab method), keep nearest. Ground colour: seeded noise asphalt/grass pattern by world position, so it moves correctly with the camera. Blob colour: olive green (about RGB 85, 95, 45) with noise. Building: grey. Sky: light blue.
   - `trajectory(n_frames, speed_mps, step_ms, alt_m=50, pitch_deg=-10, heading_deg=0, start_enu=(0, -150, 50))` → list of canonical pose rows (lat/lon/alt via `LocalFrame.from_enu`) with `t_host_ns`.
   - `make_palms_geojson(scene, frame) -> dict` matching plan 01's `palms.geojson` fields (`palm_id`, `height_m`, `crown_diam_m`, `ground_elev_m`, ...).
   - `write_fake_session(dir, scene, n_frames, offset_ms, conventions)`: writes `session.json`, `raw/triggers.csv`, `raw/poses.csv` (with SimVar-style signs per `conventions`, pose rate 3× the frame rate), and `raw/reshade/` before/after PNG pairs with packed depth. Depth PNGs use `depth.pack_log24` from FX-005.
2. `tests/unit/palmfx/conftest.py` fixtures: `synth_scene`, `synth_frame`, `synth_seq` (8 frames, 30 fps equivalent), `synth_session_dir` (uses `tmp_path`).
3. `tests/unit/palmfx/test_synth.py`: box corners rendered where `camera.project` says (within 0.5 px); GT mask pixels equal pixels whose nearest hit is a blob; `clean` differs from `color` only inside GT masks; sky depth is 0 / NaN; render of 320×180 takes < 0.5 s.

## Acceptance criteria

- [x] Tests above pass in under 2 s total.
- [x] `write_fake_session` output passes `open_session` from FX-002.
