## Goal

The exclusion margin is tuned in the Dev Mode loop until blobs disappear fully at T1 and T3 without oversized holes, and the chosen value is written to the test region YAML.

## Context

- Plan section [GEN in-sim validation](../../plans/detailed/04-fs2024-integration.md#gen-in-sim-validation); source plan section 4 (Dev Mode loop).
- Test sites T1 (palm-lined street) and T3 (palms next to buildings) from TEST-100; screenshot folders and checklist from TEST-102.
- `--margin-m` recomputes radius from `crown_diam_m` without rerunning palmscan. The only file touched under `regions/` is the test region YAML (named by DEC-004), key `exclusion.margin_m`. palmscan reads the same `exclusion.margin_m` (ARCH-003, single definition), so the next `palmscan run` writes `exclusion_radius_m` with the tuned margin; note in the Log that the region's palms need a palmscan rerun before GEN-100.

## Steps

1. For margin in 0.5, 1.0, 1.5, 2.0, 2.5 m: `python -m palmgen build --region <test> --models placeholder --margin-m <m> --skip-compile`, open in Dev Mode, build, slew to T1 and T3 viewpoints, screenshot per TEST-102 into the labelled runs `tests/visual/T1/<date>_gen017-margin/margin-<m>/` and `tests/visual/T3/<date>_gen017-margin/margin-<m>/` (variant = `margin-<m>`).
2. At each step note: blob remnants (yes/no per viewpoint), hole size relative to the palm, wall damage, autogen trees in holes.
3. Pick the smallest margin with no visible remnant at all three viewpoints; set `exclusion.margin_m` in the test region YAML.
4. If walls get cut at any margin, try `exclusion.clip_buffer_m` 0.3 → 0.6 m and record the result.
5. Write `tracking/logs/GEN-017.md` with a table margin × site × finding and the decision.

## Acceptance criteria

- [ ] Screenshots for each tried margin at T1 and T3.
- [ ] Chosen margin recorded with reasoning; test region YAML updated.
- [ ] No wall cuts at the chosen settings (human check).

## Verification

Manual: open `tests/visual/T1/<date>_gen017-margin/` and `T3/<date>_gen017-margin/`, compare margins side by side; confirm the chosen margin's screenshots show no blob remnants and no cut walls. Then `grep margin_m regions/<test>.yaml`.
