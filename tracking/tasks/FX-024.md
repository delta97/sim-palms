## Goal

STAGE B, coarse. Only after FX-100 = GO (via FX-021..FX-023); on NO-GO this task is dropped. Measure what the add-on costs per frame on the user's GPU on the fixed TEST-103 route, and compare with the DEC-005 performance budget. "A few milliseconds" is the source plan's guess; this measures it.

## Context

- Uses the TEST-103 performance harness (fixed route, PresentMon/CapFrameX capture, report script) and DEC-005's budget and reference settings.
- Integrates FX-021 (tiles), FX-022 (runtime choice) and FX-023 (pose) into one add-on build in `palmfx/addon/src/`; this is the first time all three run together.

## Steps

1. Wire the add-on: read pose, project the session's palms to tiles (port of FX-010's math), run inference on those tiles with the FX-022 runtime, composite back. Stub the sprite draw if needed.
2. Run the TEST-103 route three times each: no ReShade, ReShade without add-on, ReShade with add-on. Same DEC-005 settings.
3. Report frame time median, p95, p99 and 1 % lows for each, plus add-on GPU time per frame if measurable.
4. Write `palmfx/docs/frame-budget.md` with the table and a fits / doesn't fit statement against DEC-005.
