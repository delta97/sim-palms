## Goal

The user picks static scenery placement or live SimConnect spawning from the bake-off measurements, recorded in ADR-0008, and the losing path's tasks are dropped. Required for GATE-P5.

## Context

- Plans: `plans/05-phases.md` Phase 5 bake-off and decision table ("Static" by default); `plans/04-fs2024-integration.md` sections 2 and 6.
- Procedure: `plans/detailed/07-risks-and-open-questions.md#how-every-decision-task-runs`.
- Evidence: the bake-off report (Phase 5 task in `plans/detailed/05-phases.md`: no fix, static, live; 3 runs each); TEST-103 captures and report; ADR-0006 budget; SPIKE-005 finding on objects after disconnect; live soak test (1 hour, object count returns to zero) if run.
- Options: (1) static; (2) live; (3) hybrid (static in dense cores, live elsewhere; only if both results justify the extra complexity).
- Criteria: within ADR-0006 budget; stutter; pop-in and LOD transitions; leftover objects; moving parts.
- Default if unclear: static when results are within run-to-run noise or both are within budget.
- Risks: R-10, R-11.

## Steps

1. Collect the bake-off numbers into one table: setup | avg FPS | 1% low | p99 frametime | stutter events | pop-in notes | within budget (y/n).
2. Note SPIKE-005 and soak findings on cleanup.
3. Write `tracking/decisions/ADR-0008-static-or-live-placement.md` (Status `proposed`) with the table, options, criteria and recommendation.
4. User decides. Fill Decision and Consequences:
   - Static: `python3 scripts/tasks.py set LIVE-101 dropped --note "ADR-0008 static"`; drop ASSET-101 the same way unless it is already done; state that `palmgen` writes placements.
   - Live: LIVE-101 and ASSET-101 proceed; name the new GEN work (exclusions-only mode, spatial index output per region) as tasks to create or as notes to GEN-100's owner.
   - Hybrid: both, plus the rule for which areas use which.
   - State that DEC-003 (app language) runs next with this result as input.
5. Add a one-line `Decided (ADR-0008): ...` note to the placement section of `plans/detailed/04-fs2024-integration.md` (if missing, note in the ADR).
6. Run `python3 scripts/tasks.py validate`.

## Acceptance criteria

- [ ] ADR-0008 contains the measurement table for all three setups.

- [ ] LIVE-101 and ASSET-101 statuses match the decision (dropped for static).
- [ ] `plans/detailed/04-fs2024-integration.md` carries the decision note.
