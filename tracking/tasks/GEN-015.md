## Goal

`palmgen build --region X` runs generate → sim check → compile → output checks → reports, updates `palmfix_build.json`, and returns the documented exit code for every outcome.

## Context

- Spec: plan section [GEN build command](../../plans/detailed/04-fs2024-integration.md#gen-build-command) and the exit-code table in [palmgen CLI](../../plans/detailed/04-fs2024-integration.md#palmgen-cli).
- Reports are written even when compile or checks fail, as long as generation succeeded.

## Steps

1. Extend `run_build(opts)`: after `generate`, unless `skip_compile`: `find_fspackagetool`, sim check (refuse with `SimRunningError` unless allowed or `BUILD_WITH_SIM_OPEN`), `compile_package`, `check_outputs`.
2. On success set `compiled_package_dir` (relative to the project dir, from `find_bgls`/output layout) in `palmfix_build.json`.
3. Always `write_reports` once generation finished; then raise `OutputCheckError` if a check failed.
4. Add `runner` and `platform` injection points to `BuildOptions` (not CLI flags) for tests.
5. End-to-end tests with the fake runner from GEN-013: exit 0 with reports; 4 on non-zero tool exit; 5 on missing BGL (report says FAIL); 6 sim running; 7 tool missing; `--skip-compile` on Linux exits 0.

## Acceptance criteria

- [ ] Every exit code in the table has an end-to-end test.
- [ ] `build_report.md` exists after exits 0, 4 and 5.
- [ ] `palmfix_build.json` `compiled_package_dir` is set only on success.
