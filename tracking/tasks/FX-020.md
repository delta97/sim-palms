## Goal

The user scores the blinded packet following `palmfx/docs/judging-protocol.md`, giving the C2 and C4 inputs for the go/no-go.

## Context

- The packet path is in `palmfx/docs/stage-a-runlog.md` (FX-019).
- The judge is the user (the person who will fly with the result). Don't open `key.json` before both sheets are complete.
- Commit the filled sheets (small CSVs) and the score summary, not the images.

## Steps

1. Read `palmfx/docs/judging-protocol.md` and set up the monitor as it says.
2. First pass on stills: about 5 s per still, score every numbered blob 1-5 in `scores_stills.csv`. Optional scrutiny pass in its column.
3. Videos: watch each side-by-side at 60 fps then 30 fps, score shimmer 0-2 in `scores_temporal.csv`.
4. Copy the filled CSVs to `palmfx/docs/judging/<packet_id>/`.
5. Run `palmfx judge-score --packet <packet dir>` and save its output as `palmfx/docs/judging/<packet_id>/score-summary.json`.
6. Add `palmfx/docs/judging/<packet_id>/notes.md`: date, monitor, any problems, free comments, and the answer to "would you fly with this instead of the blob?".

## Acceptance criteria

- [ ] Every still blob and every video has a score.
- [ ] `score-summary.json` has C2 and C4 per configuration, including control-still scores.
- [ ] Notes written; key opened only after scoring (state this in notes).
