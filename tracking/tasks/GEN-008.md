## Goal

A `TemplateSet` loader and an XML writer that fill Jinja2 templates under strict rules, format numbers and GUIDs from `templates.yaml`, prove the output is well-formed, and write files only when bytes change. Built and tested on fake templates so it doesn't wait for SPIKE-003.

## Context

- Conventions: plan section [Template placeholder conventions](../../plans/detailed/04-fs2024-integration.md#template-placeholder-conventions) and [GEN templates and XML writer](../../plans/detailed/04-fs2024-integration.md#gen-templates-and-xml-writer).
- Fake templates must use obviously fake element names (`<FixtureScene>`, `<FixturePolygon>`, `<FixtureObject>`) so nobody mistakes them for real MSFS XML.
- Uses `palmgen.ids` (GEN-002) for `child_guid`/`format_guid`; if GEN-002 isn't merged, code against the signatures in the plan.

## Steps

1. `FormatSpec` dataclass from the `format` block (all keys in the plan's `templates.yaml` example).
2. `TemplateSet.load(directory)`: parse `templates.yaml` (`schema_version` must be 1), verify files exist, build a Jinja2 `Environment(loader=FileSystemLoader, undefined=StrictUndefined, autoescape=True, keep_trailing_newline=True)`, scan each template source and reject any `{%` tag other than `for`/`endfor` and any `|` filter inside `{{ }}`.
3. `TemplateSet.render(name, item_name, **values)`: inject `guid(role)` bound to `item_name` (role `"self"` returns the item's own GUID passed in `values["self_guid"]`).
4. `xml_writer.render_tile(ts, region, tile)`: order and formatting per the plan; wrap children into `scene_file` `body` as `Markup`; parse result with lxml (no entity resolution); `GenerationError` naming the template on failure.
5. `write_if_changed(path, text)` (temp file in same dir + `os.replace`; returns False and leaves mtime when bytes are equal); `count_elements(xml_text, xpath)`.
6. Fake fixture set in `tests/fixtures/palmgen/templates/`: `templates.yaml`, `scene_file.xml.j2`, `exclusion_polygon.xml.j2`, `scenery_object.xml.j2` with `count_xpath` values.
7. Tests: StrictUndefined error on missing value; forbidden construct rejected; `-0.0` printed as `0`; heading 360 → 0; XML escaping of a name with `&`; malformed template caught by lxml; write-if-changed keeps mtime; counts via XPath.

## Acceptance criteria

- [ ] Missing placeholder values raise, never render empty.
- [ ] Templates with conditionals or filters are rejected at load.
- [ ] Rendered tiles parse with lxml and element counts match inputs.
- [ ] Unchanged output leaves file mtime untouched.
