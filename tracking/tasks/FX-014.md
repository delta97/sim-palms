## Goal

`palmfx inpaint` erases masked blobs with LaMa (or the OpenCV Telea baseline), running only on padded tiles around each mask, and leaves every other pixel untouched.

## Context

- Model choice, tiling rules and VERIFY items are in the plan_ref (A10).
- Network is needed once to download weights. Unit tests use the Telea backend and must pass with no network and no torch installed (`pytest.importorskip("torch")` for the LaMa test).
- Weights go in `data/fx/models/` (gitignored). Never commit weights.
- VERIFY at download: source URL, file checksum, input convention (value range, channel order, mask polarity, required size multiple), licence. Don't guess them; read the source project's code or README and cite it in `models.lock.json`.

## Steps

1. Download the big-lama TorchScript export as distributed by the IOPaint / lama-cleaner or `simple-lama-inpainting` projects into `data/fx/models/big-lama.pt`. Write `palmfx/offline/models.lock.json`: `{"big-lama": {"url": "...", "sha256": "...", "licence": "...", "source_project": "...", "input": {"range": "...", "channels": "...", "mask": "..."}}}`.
2. `palmfx/offline/inpaint.py`:
   - `Inpainter` protocol (`name`, `inpaint(rgb, mask) -> rgb`);
   - `TeleaInpainter(radius=5)` using `cv2.inpaint(..., cv2.INPAINT_TELEA)`;
   - `LamaInpainter(weights, device)` that checks the SHA-256 against `models.lock.json`, loads with `torch.jit.load`, pads to the required multiple, runs under `torch.inference_mode()`;
   - `inpaint_tiled(rgb, mask, inpainter, pad=48, max_side=1024, feather_px=4)`: components, padded bboxes, merge overlapping tiles, multiple-of-8 sides, downscale if > max_side, paste back only inside the mask with a feathered edge.
3. `palmfx/offline/commands/inpaint.py`: `palmfx inpaint --session DIR --mask METHOD --backend lama|telea [--device cuda|cpu] [--frames a-b]` writes `inpaint/<mask>-<backend>/NNNNNN.png` and `metrics/inpaint-<mask>-<backend>-timing.json` (seconds per tile, tiles per frame, device).
4. `tests/unit/palmfx/test_inpaint.py`: pixels outside the mask are bit-identical; tiles merge when bboxes overlap; tile sides are multiples of 8; a 3000-px-wide tile is downscaled; Telea output on a synthetic frame has lower masked-region error vs the clean plate than the unedited frame does (uses FX-004 fixtures if available, else a hand-made gradient image); LaMa smoke test (skipped without torch or weights) returns the right shape and dtype.

## Acceptance criteria

- [ ] `models.lock.json` filled from the real source, with checksum and licence.
- [ ] Both backends run through `palmfx inpaint`.
- [x] Unit tests pass without network and without torch.
