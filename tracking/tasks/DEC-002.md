## Goal

The user chooses build, license or hybrid for the palm models, recorded in ADR-0003, together with a provisional answer on publishing. The task opens at the start of Phase 3 (plan 05 Phase 3 task 1) with the default "build the Mexican fan palm first" applied provisionally, so the pilot (ASSET-010..015) can run; the decision, informed by the pilot's hours where available, must be recorded before any modeling beyond the pilot (ASSET-016, then the other four species chains).

## Context

- Plans: `plans/03-palm-assets.md` sections 5 and 6; `plans/05-phases.md` Phase 3 task 1 and the decision points table ("Build one species first, then decide").
- Procedure: `plans/detailed/07-risks-and-open-questions.md#how-every-decision-task-runs`.
- Evidence: `docs/licenses/models-and-tools.md` (RISK-002); `assets/reference/build-vs-license.md` (ASSET-002: candidates, license clauses, prices, remaining work, build-hour estimate); actual pilot hours from the ASSET-010..015 Logs if they exist.
- Needed by: ASSET-016 (pilot sign-off, which also writes the `Decided (ADR-0003)` note into `plans/detailed/03-palm-assets.md`). ASSET-020/030/040/050 follow ASSET-016, so no species beyond the pilot starts before this decision.
- Options: (1) build all in Blender (20-40 h, full control, redistributable); (2) license models (fast; must allow redistribution in a mod if publishing; still needs LODs and MSFS cutout materials); (3) hybrid: licensed LOD0, hand-made LOD1-3 (license still governs).
- Default if unclear: build Mexican fan palm (`washingtonia_robusta`) first, record actual hours, then re-decide for the other four. The ADR then says "provisional; revisit after first species".
- Timing trap: DEC-001 (publish or not) is decided in Phase 6, but licensing depends on it now. Ask for a provisional publish intent here.
- Risks: R-12 (models look cheap), R-14, R-19, R-20.

## Steps

1. Ask the user: provisional publish intent (yes / no / maybe), Blender hours available per week, budget for bought models (if any).
2. From RISK-002, shortlist up to 2 licensed candidates per species with price, triangle count and the license reading. Mark any that are "restrictive" or "unclear" for redistribution.
3. Estimate: build hours (plan 03: 20-40 h total) versus license cost plus conversion hours (LODs, materials, export) per species.
4. Write `tracking/decisions/ADR-0003-build-or-license-models.md` (Status `proposed`) with options, the criteria (plan 03 acceptance checks, license fit given publish intent, cost, hours), the provisional publish intent, and the default.
5. User decides. Fill Decision and Consequences:
   - Build: ASSET per-species tasks proceed as planned.
   - License: list models to buy; add a purchase task and per-model conversion tasks via `python3 scripts/tasks.py new ASSET --title ... --phase 3`; note licensed-file storage limits for DEC-008.
   - Hybrid: both lists.
   - Provisional default: re-decision point after the first species, as a new DEC task or a note on GATE-P3 (state which).
6. Do not edit `plans/detailed/03-palm-assets.md` here: ASSET-016 adds the one-line `Decided (ADR-0003): ...` note to its build-vs-license section (ordered after this task). Say so in the ADR's Consequences.
7. Run `python3 scripts/tasks.py validate`.
