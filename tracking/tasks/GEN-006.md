## Goal

Exclusion clusters are clipped by buffered building footprints so cuts never reach walls; palms inside buildings lose both cut and object; holes are split away when the XML can't express them.

## Context

- Seven-step algorithm: plan section [GEN building clipping](../../plans/detailed/04-fs2024-integration.md#gen-building-clipping).
- Adds functions to `palmgen/geometry.py` (created by GEN-005). Don't change GEN-005 function signatures.
- `supports_holes` comes from `templates.yaml` later; take it as a parameter (default False).

## Steps

1. `ClipResult` dataclass: `parts: list[tuple[Cluster, int part, list[str] member_ids]]`, `in_building: list[str]`, `too_small: int`, `conflict_no_footprint: list[str]`.
2. `clip_buildings(clusters, footprints_local, buffer_m, min_part_area_m2, supports_holes=False, conflict_ids=frozenset())`.
3. `remove_holes(poly)` with `shapely.ops.split` by vertical lines through hole centroids; loop until no interiors; assert area preserved within 1e-6 m².
4. Tests from the plan list, including the 200-layout random property test (seeded) checking validity, non-emptiness, and zero overlap with buffered footprints (intersection area < 1e-6 m²).

## Acceptance criteria

- [ ] No output part is invalid, empty, or overlaps a buffered footprint.
- [ ] Palm inside a building is listed in `in_building`.
- [ ] Part numbering is stable across runs and input order.
- [ ] Hole removal preserves area.
