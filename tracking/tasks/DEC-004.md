## Goal

The user picks the Phase 0 test block, recorded in ADR-0005 with a name, centre point, bbox and slew start position. Every Phase 0 spike (SPIKE-003..005) and test site T1 (TEST-100) use this block, so it must be decided before Phase 0 work starts.

## Context

- Plan: `plans/05-phases.md` Phase 0 ("Pick a test block"), `plans/detailed/07-risks-and-open-questions.md#dec-004-first-test-block`.
- Procedure for all decisions: `plans/detailed/07-risks-and-open-questions.md#how-every-decision-task-runs`.
- Inventories: City of San Diego street trees, ArcGIS REST `https://webmaps.sandiego.gov/arcgis/rest/services/DSD/Environment/MapServer/20` (field `SPECIES_NAME`); City of LA via StreetsLA or the LA County compilation `https://github.com/stiles/la-trees`.
- Palm genera (SoCal): Washingtonia, Phoenix, Syagrus, Archontophoenix, Brahea, Butia, Livistona, Trachycarpus, Chamaerops, Dypsis.
- ADR template: `tracking/decisions/_TEMPLATE.md`. ADR-0005 is pre-assigned to this task; if taken, use the next free number and update `touches`.
- Decision criteria (all should hold): user knows the street in person; inside City of SD or City of LA inventory; inside photogrammetry with visible blobs in the sim; a row of 10+ palms; at least one palm within about 3 m of a building wall (Phase 0 task 4); not inside an airport boundary or a known palm mod area. If the repo is or may become public, the block should not reveal the user's home address.
- Default if the user cannot choose: a palm-lined City of San Diego street inside the `san-diego-coastal` bbox `[-117.28, 32.70, -117.15, 32.82]`.

## Steps

1. Ask the user for 1-3 candidate streets they know well (street name and cross streets, or a map pin). Do not guess personal locations.
2. If the user has none, propose 3 candidates: query the San Diego layer for palm genera inside the `san-diego-coastal` bbox (ArcGIS REST `query` with `where=SPECIES_NAME LIKE '%Washingtonia%' OR ...`, `outFields=SPECIES_NAME`, `f=geojson`, envelope geometry), group points by nearest street if an address field exists, and list streets with the most palms.
3. For each candidate, record: palm count in a ~400 m bbox, nearest palm-to-building distance (eyeball on aerial imagery is enough), whether it is near an airport.
4. Ask the user to confirm in the sim that blobs are visible (one screenshot per candidate, saved anywhere outside the repo is fine).
5. Write `tracking/decisions/ADR-0005-first-test-block.md` from the template, Status `proposed`, listing candidates against the criteria.
6. User chooses. Fill Decision with: street name, centre lon/lat (5 decimals), bbox `[lon_min, lat_min, lon_max, lat_max]` of 300-500 m, the building-adjacent palm's approximate location, a slew start position (lon, lat, altitude, heading). Set Status `accepted`, Decided by the user, date.
7. In Consequences list who consumes it: SPIKE-003 (where to draw the polygon), TEST-100 (T1), the first `regions/<name>.yaml` bbox, GATE-P0.
8. Run `python3 scripts/tasks.py validate`.
