## Goal

With Phase 3 cost known, the user decides whether the pipeline should also fix other blob trees (for example Italian cypress, eucalyptus), recorded in ADR-0007 before Phase 4 classifier work defines its classes.

## Context

- Source: `plans/07-risks-and-open-questions.md` open question 6; `plans/02-detection-pipeline.md` sections 2, 3 and 5 (genus filter, false positives, classifier).
- Procedure: `plans/detailed/07-risks-and-open-questions.md#how-every-decision-task-runs`.
- Inputs: ASSET-100 actual hours per species (from its Log), ADR-0003 route (build or license).
- Options: (1) palms only; (2) add one extra species (most common blob tree at the test sites); (3) general tall-tree species registry.
- Criteria: the other species really render as blobs (screenshots); how common they are at T1-T4 (inventory counts); whether LiDAR shape rules can separate them (see `qa_rejects.csv` from SCAN runs if available); asset hours per species.
- Default if unclear: palms only.
- Note: Italian cypress is currently a false-positive class (test site T4). Making it a target changes what T4 tests.

## Steps

1. Count inventory records of `Cupressus sempervirens` and `Eucalyptus` (any species) inside the test block bbox (ADR-0005) and any other defined test site bboxes. Use the cached inventory download under `data/` if present.
2. Ask the user for 1-2 in-sim screenshots showing whether those trees appear as blobs.
3. Record ASSET-100 actual hours per species from its Log.
4. Write `tracking/decisions/ADR-0007-scope-beyond-palms.md` (Status `proposed`) with counts, screenshots referenced by description, hours, and the options.
5. User decides. Consequences per outcome:
   - Palms only: no task changes; state that T4 keeps its false-positive meaning.
   - Extend: list new tasks to create (species key and genus list in SCAN, possible species enum change in ARCH-002's schema, new ASSET species, classifier classes for SCAN-101, T4 redefinition for TEST). Create them with `python3 scripts/tasks.py new` or name the owning area to create them.
6. Add a one-line `Decided (ADR-0007): ...` note to the species list section of `plans/detailed/03-palm-assets.md` (if missing, note in the ADR).
7. Run `python3 scripts/tasks.py validate`.

## Acceptance criteria

- [ ] ADR-0007 exists with species counts and Phase 3 hours as evidence.
- [ ] Status `accepted` (or `proposed` with default applied provisionally).
- [ ] Consequences lists affected areas and task ids, or "none" for palms only.
- [ ] `plans/detailed/03-palm-assets.md` carries the decision note.
