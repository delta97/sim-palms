## Goal

STAGE B, coarse. Only after FX-100 = GO; on NO-GO this task is dropped. A small native SimConnect client that publishes the latest camera pose into named shared memory each sim frame, and a header the add-on uses to read it without locks.

## Context

- Variables, conventions and chosen view come from `palmfx/docs/camera-simvars.md` (FX-006); calibration (vfov, bias, offset) from FX-009 output of the Stage A sessions.
- Shared memory layout: a sequence-lock header (`uint32 seq` incremented before and after each write) followed by `int64 t_qpc`, `double lat, lon, alt_msl_m, heading_deg, pitch_deg, bank_deg`, plus camera fields as confirmed. Readers retry if `seq` is odd or changed during the read.
- Native SimConnect (C++) from the MSFS 2024 SDK, so the add-on side and the helper share one header. VERIFY the 2024 SDK's native SimConnect headers and library names.

## Steps

1. Define `palmfx/addon/include/palmfx_pose_ipc.h`: struct, mapping name, version field, read/write inline helpers.
2. `palmfx/addon/posehelper/`: CMake console app; connects to SimConnect, requests the confirmed variables per visual frame (or the closest available period), writes to the mapping with QPC timestamps.
3. A tiny reader test app (in the same folder) that prints pose and age in ms at 10 Hz.
4. Measure pose age at read time (QPC now − `t_qpc`) over 1 min of flight: median and p95. Record in `palmfx/addon/posehelper/README.md`.

## Acceptance criteria

- [ ] Helper runs alongside MSFS 2024 and the reader shows live poses.
- [ ] No torn reads in a 1-minute run (reader checks a checksum field).
- [ ] Pose age median and p95 recorded.

## Verification

Manual, Windows: `cmake -S palmfx/addon/posehelper -B build/posehelper && cmake --build build/posehelper --config Release`; start MSFS 2024, run the helper, run the reader; values change as you fly; README has the age numbers.
