## Goal

A simple number for temporal shimmer: the warp-compensated frame-to-frame lightness change inside the mask, divided by the same change on untouched pixels around it, with a baseline from unedited regions. Criterion C3 uses it.

## Context

- Formulas, ring sizes, epsilon and baseline construction are in the plan_ref (A12). Pass rule C3 is in "Stage A go or no-go criteria". Implement it exactly, as constants in the module; FX-100 relies on them being frozen.
- Flow comes from FX-015's `flow.py`, computed on raw frames, filled inside the mask.

## Steps

1. `palmfx/offline/flicker.py`:
   - `lightness(rgb) -> L*` via `skimage.color.rgb2lab`;
   - `frame_error(cur, prev, flow, region, valid) -> float`;
   - `pseudo_masks(mask, forbidden, rng, tries=50) -> mask` (shift each component by a random offset to a spot not touching `forbidden` = masks ∪ sky ∪ occluder; drop components that can't be placed);
   - `flicker_series(raw, out, masks, seed=0, sky=None, occluder=None) -> FlickerReport` with per-frame `e_mask`, `e_ring`, `ratio`, sequence `median`, `p95`, baseline `base_median`, `base_p95`, and `passes_c3()` using constants `C3_MEDIAN_FACTOR = 1.5`, `C3_P95_FACTOR = 2.0`, `EPS_LSTAR = 0.5`, `RING_OUTER_PX = 15`, `RING_INNER_PX = 3`.
2. `palmfx/offline/commands/flicker.py`: `palmfx flicker --session DIR --input <stab dir name> [--seed 0]` writes `metrics/flicker-<name>.json` and prints median, p95, baselines and pass/fail.
3. `tests/unit/palmfx/test_flicker.py`: output = raw gives ratio distribution close to baseline (median within 20 %); adding independent noise inside the mask each frame increases the median ratio monotonically with noise level; a constant (perfectly stable) fill on a static camera gives ratio ≈ 0; seed makes results reproducible; `passes_c3` follows the constants.

## Acceptance criteria

- [ ] JSON output contains every field listed in Step 1.
- [ ] C3 constants match the plan's criteria table.
- [ ] Unit tests pass.
