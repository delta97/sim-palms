## Goal

Blob masks made by projecting known palm positions from `palms.geojson` into each frame, with and without a depth-consistency test. This is the method a real-time version would most likely use.

## Context

- Billboard geometry, defaults for missing fields and starting parameters are in the plan_ref (A7).
- Read the canonical `build/scan/<region>/palms.geojson` with `palmcore.palms.read_palms` (ARCH-007, validated by ARCH-002); only `palm_id`, `height_m`, `crown_diam_m`, `ground_elev_m` and the point geometry are used.
- `ground_elev_m` is null in Phase 1 output (metres, orthometric when set; ARCH-002). For a null value use the median `ground_elev_m` of palms in the same session that have one; if none have one, use the ground elevation estimate from the pose log (altitude minus AGL, if FX-006 records both; VERIFY) and flag the palm `elev_estimated` in the instance JSON.
- Metric depth comes from `frames/NNNNNN.depth.npy` (written by FX-009's `palmfx calib`). Without it, only `project-raw` is written and the command says so.
- Masks are written with `session.write_mask`; static occluder from `calib/static_occluder.png` if present.

## Steps

1. `palmfx/offline/mask_project.py`: `ProjectParams` dataclass with the plan_ref defaults; `load_palms(path) -> list[dict]` (validate, fill defaults `height_m=12`, `crown_diam_m=4`, record `defaulted: [...]` per palm); `palm_billboard(palm, frame, pose) -> np.ndarray (4,3)`; `project_masks(frame, palms, K, pose, depth_m, params) -> (raw, depth_tested)`.
2. Implementation per plan_ref steps 1-5: billboard facing the camera, `cv2.fillPoly`, skip rules, depth test `|z_pix − z_base| ≤ max(depth_tol_m, depth_tol_rel · z_base)`, dilate, occluder removal, nearer palm wins overlaps. Instance JSON carries `palm_id`, `bbox`, `area_px`, `z_m`, `base_uv`, `top_uv`, `defaulted`.
3. `palmfx/offline/commands/mask_project.py`: `palmfx mask-project --session DIR --palms GEOJSON [--no-depth-test] [--params JSON]` writes `masks/project-raw/` and `masks/project-depth/`, and `metrics/mask-project-summary.json` (palms in view per frame, skipped counts by reason).
4. `tests/unit/palmfx/test_mask_project.py` on the synthetic scene: `project-depth` IoU vs GT ≥ 0.85 per frame; palm behind the building is removed by the depth test but present in `project-raw`; palm behind the camera is skipped; missing `height_m` uses 12 m and is flagged; with `--no-depth-test` only raw masks are written.
