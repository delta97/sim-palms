## Goal

The real scene templates exist in `palmgen/templates/`, derived from SPIKE-003's Scenery Editor captures, with `templates.yaml` format rules filled from the capture notes and round-trip tests proving each template reproduces its capture byte for byte.

## Context

- Inputs (read-only): `palmgen/templates/captured/*.xml` and `captured/CAPTURE_NOTES.md` from SPIKE-003. Required list: plan section [SPIKE-003 template capture](../../plans/detailed/04-fs2024-integration.md#spike-003-template-capture).
- Rules: [Template placeholder conventions](../../plans/detailed/04-fs2024-integration.md#template-placeholder-conventions). Never invent element or attribute names; everything comes from the captures. If a capture is missing or ambiguous, set this task `blocked` and say exactly what is missing in the Log.
- Project and package-definition templates are GEN-010, not this task.

## Steps

1. Read `CAPTURE_NOTES.md`; fill `format` in `templates.yaml` (`guid_style`, decimals, `vertex_order`, `ring_closed`, `supports_holes`, `line_ending`, `scene_dir`) and `captured` metadata. Each value gets a YAML comment citing the capture file it came from.
2. Diff the two polygons in `scene_two_polygons.xml`: GUIDs that differ → `guid("self")` or `guid("<role>")`; identical → literal constants. Do the same for numbers that vary (coordinates).
3. Cut `scene_empty.xml` into `scene_file.xml.j2` with `{{ body }}` where objects go.
4. Cut the polygon fragment from `scene_one_polygon.xml` into `exclusion_polygon.xml.j2` with a `{% for v in vertices %}` loop; cut the object from `scene_one_object.xml` into `scenery_object.xml.j2` (`lat`, `lon`, `heading`, `scale`, `model_guid` as found; if heading or scale isn't encoded, omit that placeholder and note it in `templates.yaml`).
5. Set `count_xpath` for polygon and object; set `placeholder_model` from the stand-in object in the notes.
6. `test_templates_roundtrip.py`: for each template, extract values from its capture (by XPath into the capture file), render, and compare to the captured fragment bytes after line-ending normalisation. Also render a full scene of the two-polygon capture and compare to `scene_two_polygons.xml`.

## Acceptance criteria

- [ ] Every value in `templates.yaml` `format` cites a capture file.
- [ ] Round-trip tests pass for all three templates and the two-polygon scene.
- [ ] No captured file was modified (`git diff --stat palmgen/templates/captured` empty).
- [ ] `TemplateSet.load("palmgen/templates")` succeeds.
