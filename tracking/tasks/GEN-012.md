## Goal

`palmgen.pipeline.generate()` runs the full generation (load, mask, geometry, clip, variants, tiling, XML, project, metadata) and produces byte-stable project trees pinned by golden tests. `select_placements()` is exposed for `palmgen index`.

## Context

- Step order, golden cases and the update switch: plan section [GEN generate pipeline](../../plans/detailed/04-fs2024-integration.md#gen-generate-pipeline). Metadata file: [Build metadata file](../../plans/detailed/04-fs2024-integration.md#build-metadata-file).
- Uses the real templates in `palmgen/templates/` (GEN-009/010) for goldens.
- Compile, checks and reports are GEN-013/014/015. `run_build` here only calls `generate` when `--skip-compile` is set and raises `NotImplementedError` otherwise; GEN-015 completes it.
- The fixture region's airport file is `tests/fixtures/palmgen/airports_small.geojson` (GEN-007).

## Steps

1. `BuildOptions` dataclass mirroring the CLI flags plus `templates_dir: Path = Path("palmgen/templates")` and `airports_path: Path | None`.
2. `generate(opts)`: steps 1-7 from the plan; collect `BuildWarning`s and `counts` with the key names from [Build report fields](../../plans/detailed/04-fs2024-integration.md#build-report-fields); time each step into `timings`.
3. `select_placements(opts)`: steps 1-4, returning `[(Palm, Selection)]`.
4. `run_build(opts)`: lock file `build/.palmgen.lock` (exit 2 if held, removed in `finally`); with `skip_compile` call `generate` and return 0.
5. Write `palmfix_build.json` in the key order shown in the plan; `compiled_package_dir: null`; `inputs_sha256` from file bytes (templates: sha256 over sorted `*.j2` + `templates.yaml`).
6. Golden tests comparing every file under the project dir (except `palmfix_build.json` `built_utc`) against `tests/golden/gen-small-*/`; `PALMGEN_UPDATE_GOLDEN=1` rewrites goldens.
7. Idempotency test: second `generate` leaves all files byte-identical and mtimes unchanged except `palmfix_build.json`; stale tile file removal test.
